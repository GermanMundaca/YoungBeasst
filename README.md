## 🧠 Descripción

Este proyecto consiste en una landing page para un artista musical, con enfoque en:

- Presentación visual mediante video en el hero
- Sección de canciones en formato cards
- Integración con plataformas externas (YouTube, Spotify, redes sociales)
- Diseño moderno, responsive y optimizado

---

## ✨ Características principales

- 🎬 Hero con video de fondo y overlay
- 🎧 Sección de música en formato cards (sin iframes)
- 🔗 Enlaces directos a plataformas externas
- 📱 Diseño responsive


---

## ⚙️ Tecnologías utilizadas

- HTML5
- CSS3
- Bootstrap
- JavaScript
- Bootstrap Icons
